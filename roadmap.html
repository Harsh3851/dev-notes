Anti-decay system so the 10-day gap never repeats

  • 25-min sprints with 5-min breaks (every 4th break 15 min), phone in another room, one written line per sprint, last sprint = revision.
  • After-session revision (10 min) — every session ends with the day's chapter: read In simple words, retype the syntax card, answer the self-check. studydone asks for it before logging. A day without studydone is a zero day.
  • Daily 15-min drill — non-negotiable, every day, whatever the phase.
  • Spaced recall — each topic returns at +1, +3, +7, +14, +30 days after it's taught; a miss resets it to +1.
  • Saturday exit test — timed, no notes, about 30% old topics; Sunday retests the failed parts.
  • Interleaving — every new-topic session opens with one old-JS question.
  • Reminders — office days: 05:55 briefing, 06:00 morning slot, 07:30 hard stop, 20:45 evening nudge, 22:15 last call · off days: 10:00 + 17:00, 21:30 last call · studydone to log.
  • Gap rule — miss 2+ days → first session back is recall only, no new content.
  • 🟢 means solved cold, twice, at least a week apart. Familiar is not the same as confident.

The weekly rhythm

  • Office days 06:00–07:30 (learn/build, fresh brain) + 20:45 onwards for 60–90 min (drill, recall, revision) · days off ~4 h (build days) · ≈ 15.5 h/week, planned on what actually happens, not on the cap
  • Saturday = exit test first, then build · Sunday = build day + retest · Monday = weekly review opens the new week
  • Mock interviews on 28-11, 26-12, 28-12 · final exit exam 30-12
  • A missed day costs one day, never the week — the piece moves to the next Saturday (max +1 h); the backlog is never stacked

Daily drill minimum viable session · 15 min

Every session opens with it; on a bad day it is the session:

  • 1 output prediction (JS now; Node/React later) — tag every line N / U / T before answering
  • 1 theory question, answered out loud — the 30-second version
  • 1 micro coding problem (5–10 min)
  • 1 recall from the spaced queue — intervals 1 → 3 → 7 → 14 → 30 days; a miss resets to 1. this in callbacks stays on the daily list until five clean hits in a row.
